# 港澳附近遊 implementation plan
Approved scope: Macau/Hong Kong, variable member list, nearby real POIs, timed suggested itinerary, weather reminders, map route geometry and transport guidance.
Architecture: nearby_sources.py provides cached Photon/Overpass/OSRM/Open-Meteo data with attribution; optional Amap POI/walking backend uses GCJ-02 without mixing map coordinates. nearby_planner.py validates requests and uses deterministic route/time checks plus optional LLM candidate IDs. Flask adds /nearby-plan and /nearby-weather; chat routes nearby intent to same planner. Web form permits member rows with no fixed count; separate map supports WGS84 Leaflet or configured Amap. Preserve existing foundation.
Tasks: write regressions; implement sources; planner; HTTP/chat integration; UI; offline and live source tests; JS/browser check; documentation.
Limits: no Xiaohongshu connector authorization available, so no claim of live Xiaohongshu search. Opening hours, dietary suitability and prices unknown unless provided by source. Transit query link is not verified transit service. Weather refresh while page open, no background daemon. Suggested durations are estimates, not opening-hour validated reservations. Unknown route means timing remains provisional, never fabricated geometry.
