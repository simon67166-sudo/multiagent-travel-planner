# 机票/酒店真实数据源调研

`ota_hotel_agent.py` 现在还是纯占位假数据（一条写死的机票+一条写死的酒店），这份文档记录调研过的真实数据源，方便以后接的时候直接抄，不用重新查一遍。调研时间 2026-09-11。

## 结论先行

免费 + 实时 + 真机票价格这个组合基本不存在——票价数据背后要接 GDS/航司系统，数据源本身有成本。现实预期是"小额免费额度先测通，需要更多调用量花几十到几百块钱"，这个价位对竞赛项目可以接受。

## 已排除的方案

### 飞猪开放平台（open.alitrip.com / open.fliggy.com）—— 走不通
本质是"商家入驻"平台，不是"数据查询"平台：
- 机票类目商家身份限航空公司/机票代理商，**邀请制招商**（不接受自由申请），需要三证合一营业执照（注册资金 ≥30万元）+ 法人身份证，个人/学生团队没有申请入口
- 入驻本身要求**店铺（非个人）淘宝账号**，绑定支付宝
- 核心 API（比如 `taobao.alitrip.travel.item.sku.override`）是让商家把**自己已上架商品**的价格库存"写入/覆盖"进飞猪系统，跟"查询市场上真实机票酒店数据"是反着来的两件事——需要预先有 `itemId`（自己的商品 ID）和已授权商家账号的 `sessionKey`
- 结论：除非团队本身有旅行社/机票代理资质，这条路对竞赛项目不现实

### 聚合数据（juhe.cn）—— 没有免费额度
[航班时刻票价查询API](https://www.juhe.cn/docs/api/id/96) 页面写的是"账户充值后才能购买使用"，不是"免费额度用完再收费"，实际上是要先充钱才能调用，不算真正的免费方案。

### 爬虫路线 —— 不建议
评估过，放弃：违反 OTA 平台服务条款（携程/飞猪/去哪儿用户协议都明确禁止未授权抓取），国内有真实法律风险（反不正当竞争法/非法获取计算机信息系统数据罪相关案例集中在票务旅游领域）；技术上这些平台反爬手段也不弱（设备指纹/JS挑战/IP限速）；爬到的还是页面展示价，跟实际下单价经常对不上，数据可信度也存疑。

## 可用方案

### 机票 —— 极速数据（jisuapi.com）：推荐
- [航班查询API](https://m.jisuapi.com/api/flight/)
- **免费额度**：10次（不多，够先跑通代码验证接口）
- **付费**：450元/10000次（约0.045元/次），Level2/3/4 更大量更便宜
- **真的有价格数据**：返回字段里有 `pricelist`（各舱位价格）、`minprice`（最低价）、`airporttax`/`fueltax`（机建燃油费），不是只有航班时刻/状态
- 待办：注册账号，用免费的10次测一下真实返回结构，再决定怎么接进 `ota_hotel_agent.py`

### 机票（备选，仅动态无价格）—— Aviationstack
- [aviationstack.com](https://aviationstack.com/)
- 免费 100次/月，全球航线覆盖广
- **没有票价数据**，只有航班实时状态/时刻（起降时间、延误、登机口）——如果只是想展示"真实航班动态"而不强求价格可以配合用，国内航线覆盖情况没细查

### 酒店 —— 阿里云 API 市场 / 易源数据「酒店查询」
- 活动价 **¥0.01元/100次**，基本等于免费
- 产品页：`https://market.aliyun.com/products/57096001/cmapi011531.html`
- 具体返回字段（是否有真实价格/库存）没有确认，注册后看文档才知道，需要实测

### 酒店/机票（备选，门槛稍高但更权威）—— 携程开放平台
- 个人开发者做实名认证（身份证）就能申请，1-3个工作日审核，通过后拿 App Key/Secret
- 可以申请"酒店详情查询"这类接口
- 比飞猪现实很多，值得跟极速数据/易源数据并行申请，作为后续升级路径
